# 002 BM25 검색

## 목적
질문에 맞는 조문을 찾는 첫 기준 검색. 이후 의미 검색·하이브리드와 비교할 기준 점수가 된다.

## 입력·출력
- 입력: 질문 문자열, 쪼갠 단위(조/항), 제목 붙이기 여부, 상위 개수 k
- 출력: (덩어리, 점수) 목록, 점수 높은 순

## 동작 규칙
- 덩어리: `data/processed/chunks_article.jsonl` 또는 `chunks_paragraph.jsonl`
- 토큰: 공백·문장부호로 나눈 어절 + 어절 안의 글자 두 개 묶음 (예: "갱신요구" → 갱신요구, 갱신, 신요, 요구). 형태소 분석기 없이 조사가 붙은 말("갱신을")도 맞도록
- 점수: BM25 (k1=1.5, b=0.75), 계산식은 코드에 직접 작성 (외부 검색 라이브러리 안 씀)
- 색인은 처음 한 번 메모리에 만듦 (덩어리 1,135개라 충분)

## 하지 않는 것
- 역할 필터, 시행령 연결 (실험 3·4에서)
- 의미 검색 (다음 명세)

## 확인 방법
- `python src/evaluate.py` → 정답지 확정 문항(verified=true)의 조문 재현율@5를 조 단위·항 단위 × 제목 유무 4가지로 출력하고 `eval/results/`에 저장
- 정답 조문이 상위 5개에 없는 문항은 문항 번호를 출력 (실패 원인 분류용)

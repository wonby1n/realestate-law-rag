# 004 임베딩 검색과 하이브리드

## 목적
BM25는 단어가 겹쳐야 찾는다. "월세↔차임", "아무 말도 안 하면↔갱신거절의 통지를 하지 아니한" 같은 뜻 일치를 임베딩으로 잡고, BM25와 합쳐(하이브리드) 둘의 장점을 함께 쓴다 (실험 2).

## 입력·출력
- 입력: 질문, 쪼갠 단위(조/항), 방식(bm25 / dense / hybrid), k
- 출력: (덩어리, 점수) 목록

## 동작 규칙
- 임베딩 모델: `BAAI/bge-m3` (다국어·한국어 지원, 최대 8,192 토큰이라 긴 조문도 자르지 않음). 노트북 GPU(RTX 4050 6GB)에서 fp16
- 덩어리는 `text_with_title`을 임베딩 (E01에서 제목 붙임이 나았음)
- 유사도: 정규화한 벡터의 내적(코사인)
- 덩어리 임베딩은 한 번 계산해 `data/index/{단위}_{모델}.npy`에 저장, 덩어리 파일이 바뀌면 다시 계산 (파일 수정 시각 비교)
- 질문: dense는 원래 질문 그대로, BM25는 질문 다듬기(003) 적용 — 두 경우 모두 비교해 본다
- 하이브리드: RRF(순위 역수 합, k=60). 점수 크기가 다른 두 방식을 순위로만 합친다
- 항 단위 결과는 E01과 같이 조로 묶어 평가

## 하지 않는 것
- 리랭커(교차 인코더), 역할 반영, 시행령 연결 → 다음 실험
- 다른 임베딩 모델 비교 → 이번 결과를 보고 결정

## 확인 방법
- `python src/evaluate.py` → bm25 / dense / hybrid × 조 / 항 재현율@5 표, `eval/results/`에 저장
- E01·E02에서 놓친 문항(T03, T06, T13, T15, T26, T30 등) 중 무엇을 새로 맞히고 무엇을 새로 놓치는지 문항별로 확인
- 화면에서 검색 방식을 고를 수 있음

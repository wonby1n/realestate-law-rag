# 003 질문 다듬기 (일상어 → 법률 용어, 금액·날짜 빼기)

## 목적
2026-11-20 화면 테스트: "월세가 50만원인데 집주인이 재계약하면서 60만원으로 올린대. 이거 맞아?" → 정답(주택임대차보호법 제7조, 제6조의3)이 상위 5개에 없고 포상금·과태료 조문이 1위.

점수를 나눠 보니 원인은 두 가지였다.
1. **말이 다름**: 질문은 "월세·집주인·올린대", 법은 "차임·임대인·증액". "월세"가 나오는 조문은 전체 395개 중 1개, "차임"은 17개.
2. **금액이 엉뚱한 조문과 맞음**: "50", "만원", "만원으로"가 포상금(50만원)·과태료 조문과 맞아서 점수를 올림.

## 입력·출력
- 입력: 사용자 질문
- 출력: 검색용 질문 (원래 질문 + 법률 용어 덧붙임, 금액·날짜 제거), 그리고 무엇을 바꿨는지 목록 (화면에 보여 줌)

## 동작 규칙
- 금액·날짜·기간 표현(`50만원`, `2025년`, `3월 1일`, `2년`, `5%`)은 검색어에서 뺀다. 숫자는 나중에 계산 단계에서 쓴다.
  - 단, `제6조의3`, `제7조`처럼 조문 번호는 남긴다.
- 일상어 사전(`src/query.py`의 `SYNONYMS`)에 있는 말이 나오면 법률 용어를 뒤에 덧붙인다 (바꾸지 않고 덧붙임 → 원래 말로 맞는 조문도 유지).

## 하지 않는 것
- LLM으로 질문 고쳐 쓰기 (답변 단계에서 비교)
- 사전을 평가 질문에 맞춰 늘리기. **평가 점수를 올리려고 정답지 질문의 단어를 사전에 넣지 않는다** (과적합). 사전은 실무에서 쓰는 말 기준으로 만들고, 항목마다 출처를 적는다.

## 확인 방법
- 화면에서 위 질문 → 주택임대차보호법 제7조가 상위 5개에 나옴
- `python src/evaluate.py` → 다듬기 전후 재현율@5 비교, 새로 맞힌 문항과 새로 틀린 문항을 모두 확인

## 결과
2026-11-20 조 단위·제목 붙임 기준 재현율@5 0.704 → 0.778, 새로 틀린 문항 없음. 화면 질문(T30)은 제6조의3 1위로 올라왔지만 제7조는 11위로 절반만 해결. 확인 중 `제6조의3`의 3이 지워지는 버그를 찾아 고침. 자세히 → [EXPERIMENTS.md E02](../EXPERIMENTS.md)

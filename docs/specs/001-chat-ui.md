# 001 채팅 화면

## 목적
질문을 넣고 검색·답변 결과를 눈으로 보면서 개발한다. 나중에는 실제 사용 화면이 된다.

## 입력·출력
- 입력: 왼쪽 칸에서 역할(임차인/임대인/시행사/시공사/잘 모름), 쪼갠 단위, 제목 붙이기 여부 / 대화창에 질문
- 출력: 말풍선. 지금 단계는 검색된 조문 상위 5개 (법령·조·항, 점수, 펼치면 원문과 시행일)

## 동작 규칙
- 대화 기록은 화면을 새로 고치기 전까지 유지
- 질문마다 질문·설정·검색 결과 id를 `logs/chat_YYYYMMDD.jsonl`에 한 줄씩 남김 (git 제외)
- 맨 아래 안내: 참고용이며 법률 자문이 아님

## 추가 (2026-11-20, 본인 요청)
- 검색된 조문마다 국가법령정보센터 링크 → 누르면 그 조문으로 바로 이동 (`src/links.py`)
- 링크는 현행 조문을 열기 때문에, 수집한 시행일을 옆에 같이 보여 줌

## 하지 않는 것 (다음 단계)
- LLM 답변 생성, 되묻기, 날짜 계산 → 결론/계산 칸은 답변 단계에서 추가
- 역할 선택은 지금은 기록만 하고 검색에 반영하지 않음 (실험 3 전)

## 확인 방법
- `.venv/bin/streamlit run app/chat.py` → 브라우저에서 "계약갱신요구권은 몇 번 쓸 수 있나요?" 입력 → 주택임대차보호법 제6조의3이 결과에 보임
- `logs/`에 한 줄이 쌓임

## 결과
2026-11-20 화면을 띄워 확인 (Streamlit 1.67.0). "계약갱신요구권은 몇 번 쓸 수 있나요?" → 1위 주택임대차보호법 제6조의3(점수 30.1), `logs/chat_20261120.jsonl`에 한 줄 기록됨

# app — 채팅 화면

카카오톡·챗GPT처럼 **말풍선으로 묻고 답하는 화면**. 검색이 붙는 3주차에 실제로 연결한다.

- 도구: Streamlit (`st.chat_input`, `st.chat_message`) — 화면도 Python으로만 짠다
- 실행(예정): `streamlit run app/chat.py`

## 화면

```
┌ 왼쪽 ───────────┐┌ 대화 ─────────────────────────────────────────┐
│ 내 역할         ││                    나 2025년 3월 1일 계약인데 │
│ ○ 임차인        ││                                  갱신 가능? 🙋 │
│ ○ 임대인        ││ 🤖 결론을 내려면 하나만 더 알려 주세요.        │
│ ○ 시행사        ││    계약 기간이 2년인가요? 갱신한 적이 있나요? │
│ ○ 시공사        ││                       2년이고 처음이야 🙋     │
│ ○ 잘 모름       ││ 🤖 결론: 갱신 요구 가능                        │
│                 ││    계산: 만료 2027-02-28 →                     │
│ 기준일          ││          요구 가능 기간 2026-08-28~2026-12-28  │
│ [2026-11-20]    ││    근거 ▸ 주택임대차보호법 제6조의3 ①②        │
│                 ││         (시행 2026-01-02)                      │
│ [대화 지우기]   ││    ※ 참고용이며 법률 자문이 아닙니다           │
└─────────────────┘└───────────────────────────────────────────────┘
```

## 답변 말풍선 구성

| 칸 | 내용 |
|---|---|
| 결론 | 한 줄. 경계일에 걸리거나 정보가 모자라면 단정하지 않고 되묻기 |
| 계산 | 날짜·금액을 계산했으면 과정을 그대로 보여 줌 (도구 결과) |
| 근거 | 조문 이름 + 시행일. 누르면 원문이 펼쳐짐 |
| 안내 | 법률 자문 아님 / 범위 밖이면 "법령으로 답할 수 없음"과 이유 |

## 운영 기록

- 대화마다 질문·검색된 조문·답변을 `logs/`에 남긴다 (git 제외).
- 틀렸거나 답을 못한 질문은 원문 대조 후 `eval/` 정답지에 추가한다 → 실제로 쓰면서 평가 질문이 늘어나는 구조.

# realestate-law-rag — 역할별 부동산 법령 RAG

부동산 법령(주택임대차보호법·민간임대주택법·주택법·공동주택관리법 등)을 조문 단위로 수집·색인하고,
**묻는 사람의 역할(임차인 / 임대인 / 시행사 / 시공사)** 에 맞춰 근거 조문을 찾아 답하는 RAG.

> 이 서비스의 답변은 참고용이며 법률 자문이 아닙니다. 답변에 붙은 근거 조문과 시행일을 반드시 확인하세요.

## 왜 역할별인가

같은 "보증금" 질문도 묻는 사람에 따라 봐야 할 법이 다르다.

| 역할 | 주로 묻는 것 | 먼저 볼 법령 |
|---|---|---|
| 임차인 | 계약갱신, 보증금 보호, 임대료 인상 한도, 중개보수 | 주택임대차보호법, 공인중개사법, (등록 임대주택이면) 민간임대주택법 |
| 임대인 | 갱신 거절 사유, 임대사업자 의무, 보증 가입 | 주택임대차보호법, 민간임대주택법 |
| 시행사 | 사업계획승인, 주택건설사업 등록, 공공지원민간임대 | 주택법, 민간임대주택법 |
| 시공사 | 하자담보책임, 하자 분쟁, 하도급 | 공동주택관리법, 건설산업기본법 |

하지만 경계가 겹친다. 등록 임대사업자의 주택에 사는 임차인은 주택임대차보호법보다 민간임대주택법이 먼저 적용되는 조항이 있다.
그래서 역할을 **검색 필터로 쓸지, 가중치로만 쓸지**를 실험으로 정한다 → [docs/PLAN.md](docs/PLAN.md)

## 구성 (계획)

```
국가법령정보센터 공개 API
  → 수집(raw, 법령·시행일자별 원문 보관)
  → 파싱(편·장·조·항·호·목 계층, 시행령 연결)
  → 쪼개기(조 단위 / 항 단위 비교)
  → 색인(Elasticsearch: Nori BM25 + 벡터, 하이브리드)
  → 검색(역할 반영) → 답변(근거 조문 인용 필수, 근거 없으면 답하지 않음)
  → 평가(실무 질문 정답지)
  → 갱신(시행일자가 바뀐 법령만 다시 처리)
```

- 언어: Python 3.12
- 검색: BM25 직접 구현 → 의미 검색·하이브리드와 비교
- 화면: Streamlit 채팅

## 실행

```bash
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
.venv/bin/python src/collect.py     # 법령 수집 (.env에 OC 필요)
.venv/bin/python src/parse.py       # 조·항 쪼개기
.venv/bin/python src/evaluate.py    # 검색 평가
.venv/bin/streamlit run app/chat.py # 채팅 화면
```
